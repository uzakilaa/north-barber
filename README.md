# ✂️ North Barber — сайт барбершопа

Одностраничный сайт мужского барбершопа: услуги и цены, мастера, контакты и онлайн-запись.

**🔗 Демо:** https://uzakilaa.github.io/north-barber/

## Стек
- HTML5
- CSS3: Flexbox, Grid, адаптивная вёрстка
- JavaScript (vanilla): рендер данных, валидация формы, localStorage

## Что реализовано
- Адаптивное меню-бургер (закрывается по Esc и клику по ссылке)
- Услуги, цены и карточки мастеров генерируются из данных в JS
- Форма онлайн-записи: валидация полей, маска телефона, выбор услуги, мастера и даты
- Данные клиента запоминаются в localStorage
- Доступность: aria-атрибуты, понятные сообщения об ошибках

## Запуск
Скачайте репозиторий и откройте `index.html` в браузере.
